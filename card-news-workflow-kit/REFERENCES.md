# 공식 문서와 형식 레퍼런스
확인 기준: 2026-09-08. CLI는 설치 버전의 help도 확인합니다.

## 실행과 사용자 질문
- [Claude Agent SDK 사용자 입력](https://code.claude.com/docs/en/agent-sdk/user-input): AskUserQuestion을 앱의 사용자 입력과 연결.
- [Claude Agent SDK 세션](https://code.claude.com/docs/en/agent-sdk/sessions): 명시적인 세션 재개.
- [Claude CLI headless](https://code.claude.com/docs/en/headless): claude -p, JSON 결과, --resume.
- [OpenCode CLI](https://opencode.ai/docs/cli/): opencode run, --format json, --session.
- [OpenCode 실행 구현](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/cli/cmd/run.ts): 줄 단위 이벤트 출력 확인.
- [Antigravity CLI 설치](https://www.antigravity.google/docs/cli/install/)
- [Antigravity headless 실행](https://www.antigravity.google/docs/cli/headless/)
- [Antigravity 도구](https://www.antigravity.google/docs/sdk/tools/): 내장 generate_image. 이미지 전용 서브명령을 임의로 만들지 않습니다.

## 카드뉴스 형식
아래 자료의 정보 순서·표지 역할·그림과 글의 관계를 비교하세요. 레퍼런스의 이미지나 템플릿을 자유롭게 재배포할 수 있다는 의미는 아닙니다.

- [질병관리청 손 씻기 카드뉴스](https://health.kdca.go.kr/healthinfo/biz/health/ntcnInfo/healthSourc/cardNews/cardNewsView.do?card_news_sn=68): 행동을 설명하는 단계형 구성.
- [강원대학교 연구노트 안내](https://uicf.kangwon.ac.kr/Uploads/News/11051113LZKJ.pdf): 정의·절차와 체크리스트. 모바일에서는 항목을 여러 장으로 분리하는 것을 제안합니다.
- [Canva 사진 중심 캐러셀](https://www.canva.com/templates/EAGsIkN2E0w-simple-classic-elegant-photo-centric-seamless-instagram-portrait-carousel/): 사진 중심 형식 참고.
- [Canva 스크랩북 캐러셀](https://www.canva.com/templates/EAHKCACEETY-colorful-scrapbook-photo-diary-carousel-instagram-post/): 사진 일기 형식 참고.
- [Canva 스토리텔링 캐러셀](https://www.canva.com/templates/EAGo8azJCtM-neutral-aesthetic-storytelling-carousel-instagram-post/): 이야기 순서 형식 참고.
- [Adobe 캐러셀 제작 가이드](https://www.adobe.com/express/learn/blog/carousels-stand-out): 설명·목록·비교 등 여러 형식과 표지의 역할.
