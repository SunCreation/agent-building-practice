# 카드뉴스 작업실 — 실제 실행 구현

주제 입력 → 실제 웹 조사 → 브라우저 후보 선택 → 심층 조사 → 독자 질문 → 스토리보드 승인 → Antigravity 이미지 생성 → 한국어 카드 렌더링 → 부분 수정 → 최종 승인·ZIP 다운로드를 연결한 로컬 앱입니다.

## 실행
Python 3.11 이상, uv, 로그인된 Claude Code CLI(`claude`)와 Antigravity CLI(`agy`)가 필요합니다. 현재 실제 연결 엔진은 **Claude CLI 하나**입니다. Claude SDK/OpenCode는 PRD의 확장 선택지이며 이 구현에서 지원한다고 표시하지 않습니다.

압축을 푼 폴더에서 실행하세요.

```bash
uv sync --locked
uv run playwright install chromium
uv run run.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 포트 충돌 시 `uv run run.py --port 8766`처럼 바꿉니다. `AI 최신소식`을 입력하고 기다립니다. 검색 후보에서 1~3개를 선택하고, 독자 질문에 답한 뒤 스토리보드를 승인하세요. 이미지 생성 후 카드 미리보기를 확인하고 최종 승인하면 ZIP을 받을 수 있습니다.

Claude는 WebSearch/WebFetch/Read만 허용하며 실제 검색 도구를 사용합니다. 설치 계정의 모델·검색 이용 가능 여부와 사용량 제한이 적용됩니다. Antigravity 이미지 작업은 `--dangerously-skip-permissions`로 해당 실행의 도구 요청을 자동 승인합니다. 사용자 본인이 승인한 로컬 작업에서 사용하고, 공개 서비스로 그대로 노출하지 마세요. 전역 권한 설정은 수정하지 않습니다. 생성 이미지를 기존 예시로 대체하지 않습니다.

## 첫 카드 후킹과 기획 피드백

초기 기획과 재기획 모두 **후킹 설계 → 카드 작성 → 사용자 검토**로 진행합니다. 첫 모델 호출은 독자의 관심, 궁금증, 확인된 근거, 뒤 카드에서 해소할 내용과 과장 위험을 기준으로 서로 다른 후킹 두 개를 비교합니다. 두 번째 호출은 선정한 문구를 첫 카드 제목에 그대로 쓰고 뒤 카드에서 그 기대를 해소합니다. 앱은 선정 문구와 첫 제목의 일치를 검사합니다. 이 검사는 문구 반영을 보장하며, 실제 클릭률이나 흥미를 보장하는 평가는 아닙니다.

기획 화면의 **기획 수정 피드백**에 바꾸고 싶은 내용을 적고 **피드백으로 기획 다시 작성**을 누르세요. 예: “첫 카드는 식당 사장님이 다음 장을 넘기고 싶은 질문으로 시작해 줘. 확인되지 않은 원가 절감은 약속하지 마.” 수정 후에도 이미지 생성 전 승인을 다시 받습니다. 실패하면 기존 기획을 보존하고 같은 요청을 재시도할 수 있습니다. 수정 전 기획과 피드백은 프로젝트의 plan_history에 저장됩니다.

## 작업 진행 내역

진행 중에는 **작업 진행 내역** 토글에서 실제 검색어, 읽는 페이지 주소, 도구 시작과 결과 수신을 시간순으로 확인합니다. CLI의 스트림을 받아 약 2초마다 화면에 반영합니다. 공개할 새 활동이 없으면 15초마다 프로세스가 아직 종료되지 않았고 응답을 기다리는 상태를 기록합니다. 이는 성공이나 진행률을 뜻하지 않습니다.

현재 단계 경과 시간과 마지막 서버 응답도 표시합니다. 토글을 닫아 두어도 기록은 쌓이며, 이전 기록을 읽으려고 위로 스크롤하면 위치를 유지합니다. 맨 아래를 보고 있을 때만 새 기록을 따라갑니다. 모델의 내부 사고 과정, 도구 결과 원문, 인증 정보는 표시하지 않습니다.

## 저장과 재시도
`workspace/<프로젝트ID>`에 프로젝트·Claude 세션 ID·실행 증거·이미지·버전별 결과를 저장합니다. 새로고침 뒤에는 저장된 작업을 선택할 수 있습니다. 검색이나 이미지 생성 실패는 오류로 표시하고 같은 단계에서 재시도합니다. 중단된 작업은 재시작 시 명확히 표시합니다.

조사·생성 호출의 기본 제한은 600초입니다. 필요하면 실행 전에 `CARD_NEWS_TIMEOUT` 환경변수로 초 단위를 지정합니다.

실제 실행 검증은 macOS에서 수행했습니다. Linux에서 한글이 표시되지 않으면 Noto Sans CJK 같은 한글 글꼴이 필요합니다. Windows·Linux의 전체 모델 실행은 별도 확인이 필요합니다.

현재 구현은 한 사용자·한 서버 프로세스용입니다. 동시에 여러 서버 워커를 띄우지 마세요. 각 프로젝트의 CLI 세션은 분리됩니다. API키를 입력하는 화면은 없고 CLI에 이미 로그인한 계정을 이용합니다.
