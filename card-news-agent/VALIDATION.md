# 실행 검증 기록

검증일: 2026-09-08. 실제 실행과 자동 검사를 분리해 기록합니다.

## 자동 검사
- 렌더링: 실제 PNG와 Chromium으로 1080×1350 카드/ZIP 생성, 잘림 감지, 한 카드 수정 시 나머지 PNG 동일성 확인.
- API: 잘못된 선택, 지난 질문 답변, 중복 제출, 승인 전 ZIP 차단, 저장 상태 복구, 취소 등 상태 검사. 이 검사에서는 모델 작업을 대체하므로 실제 모델 성공의 증거가 아닙니다.
- CLI 연결: JSON·도구 결과 판정, 시간초과·취소, 실제 PNG 검증과 실패 처리. 이 검사도 실제 모델 호출과 구분합니다.

## 실제 실행
Claude CLI의 실제 WebSearch/WebFetch, 명시적 세션 이어가기, Antigravity CLI의 실제 generate_image, Chromium 렌더링을 사용하는 실행입니다. 첫 조사 시도는 240초 제한으로 실패했습니다. 화면의 오류 및 재시도 동작을 확인했고, 제한을 환경변수 CARD_NEWS_TIMEOUT으로 설정할 수 있도록 바꾸고 기본값을 600초로 조정했습니다.

### 실행하면서 고친 문제

- 첫 조사 240초 제한 초과: 기본 600초 및 환경변수 설정으로 변경. 실패·재시도 과정을 숨기지 않음.
- 승인 전 ZIP 링크 노출: 승인 전에는 비활성 안내, 승인 후 다운로드 허용.
- 새 주제 버튼이 작업 후 계속 비활성화: 상태에 따라 다시 활성화.
- 매 2초마다 동일 화면 DOM 교체로 취소 버튼의 대상이 사라짐: 실제 데이터가 달라질 때만 화면 갱신. 수정 후 브라우저 취소 성공.
- 실패 뒤 남은 이미지 재사용 가능성: generated 표시와 해시가 맞는 검증 기록이 있어야 재사용.
- 공백 주제·잘못된 후보·원문 URL 검증, 중단 작업 처리 보완.
- 참고 구현 밖의 이미지 파일에 의존하던 렌더러 테스트: ZIP에 포함한 실제 생성 이미지를 사용하도록 수정.

### 자동 검사 결과와 한계

28개 테스트와 3개 하위 사례 통과. 글자 넘침 자동 축약 등 예외 경로는 단위 테스트로 확인했으며, 이번 실제 카드 생성에서는 넘침이 발생하지 않았습니다.

전체 제작 성공 사례는 현재 **한 주제, 한 실행 엔진(Claude CLI)**입니다. Claude SDK·OpenCode 실행은 미구현이며 검증했다고 하지 않습니다. 배경 한 장을 공유하는 1080×1350 텍스트 중심 카드이며, 카드별 이미지 재생성·다른 비율·스토리보드 단계의 직접 편집·서버 다중 사용자·Windows/Linux 전체 실행은 확장 또는 추가 검증이 필요합니다. 원본 PRD의 모든 수용 조건을 완전히 구현한 제품으로 간주하지 않습니다.

### 배포 ZIP 재검증

배포 ZIP을 별도 임시 폴더에 풀어 `uv sync --locked`, `uv run pytest -q`, `uv run run.py --port 8766`을 실행했습니다. 28개 테스트·3개 하위 사례 통과, HTTP 200 및 실제 앱 HTML 확인. 모델을 다시 호출한 검사가 아니라 배포 구성·실행 명령의 재현 확인입니다.

## 진행 내역 스트리밍 보완 (2026-09-09)

Chrome에서 기록 4개일 때 토글을 닫고 7개로 늘어난 후에도 닫힘이 유지되는 것을 확인했습니다. 다시 열었을 때 누적 기록이 표시됐습니다. 실제 화면은 `examples/screenshots/10-live-progress.png`입니다. 사용자 작업은 질문 대기 상태에서 보존하고 서버에 변경을 반영했습니다.
