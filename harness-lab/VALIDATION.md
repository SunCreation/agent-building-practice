# 검증 기록

이 문서는 실행한 검사와 아직 실행하지 않은 측정을 구분합니다. 아래 로컬 확인은 Terminal-Bench Pro 점수가 아닙니다.

전체 자동 검사 47개가 통과했습니다. 특수 파일 읽기·승인 중 파일 변경·원자적 교체 실패 회귀검사와 벤치마크 실행/집계 연결 검사도 포함합니다.

## 확인한 범위
- Python 3.13, OpenAI SDK 2.54.0, Harbor 0.22.0의 설치와 실제 API 스키마 대조.
- 모의 모델의 도구 요청→검사→실행→결과 연결, 종료·시간 제한, 승인 거절, 세션 복구 및 제공자 변환 단위 테스트.
- 모의 Harbor 환경의 명령 전달, 잘못된 인자 차단, 독립 채점 결과 집계 테스트.
- 점수 분모 고정, 실행 오류·미완료·중복 결과·알 수 없는 사용량, Oracle 구별, HTML/CSV 출력 테스트.
- 원본 task.toml 기준 easy 2·hard 8, 8개 분야, GPU 0 선언을 고정 커밋에서 확인. 문제 정답/숨은 테스트는 선정에 사용하지 않음.
- 실제 Harbor JobConfig로 10문항·순차 실행·재시도 0회 설정을 검증.

## 로컬 Ollama 실측
모델: `qwen3.5:2b`.

| 작은 작업 | 관찰 |
|---|---|
| 가상 모임 파일 읽기 | 모델 호출 2회·파일 도구 1회. 오후 3시와 책 한 권·필기구 답변을 원문과 대조하여 확인. 약 8.9초. |
| 영수증 함수 수정 | 모델 호출 6회·도구 6회 후 실패 종료. 독립 unittest 재실행에서 3개 중 1개 실패. 테스트 파일 불변 확인. 약 36.7초. |

읽기 성공은 도구 연결의 한 사례이고 코딩 실패는 그대로 남겼습니다. 작은 모델의 실패를 예시 하네스가 모든 문제를 해결한다는 주장으로 바꾸지 않습니다. 단위 테스트와 별개로 학생이 선택한 실제 모델을 검증해야 합니다.

## 미측정 범위
작성 환경에 Docker CLI/엔진과 OpenAI API 키가 없어 실제 Terminal-Bench Pro 컨테이너 빌드, Oracle 환경 검사, OpenAI 모델 호출, 10문항 기준·개선 성능은 **NOT_RUN**입니다. 원본의 환경 요구사항은 선언을 확인한 것이며 빌드 성공 인증이 아닙니다. 실제 점수나 예시 성공률을 만들지 않았습니다.

학생의 제출물에는 위 미측정 문서를 복사하는 것으로 끝내지 않고, 자신의 실행 환경에서 얻은 10문항 원본 결과와 개선 실험을 기록해야 합니다. 문제별 환경 실패는 원인과 함께 보존하고 해결·재실행 여부를 설명합니다.
