# 에이전트 제작 실습 자료

Python으로 직접 만드는 범용·코딩 하네스와, 기존 SDK·CLI를 조립하는 카드뉴스 제작기입니다.

- [Agent Harness Practice](agent-harness-practice/README.md): OpenAI API / Ollama, 직접 구현한 도구 호출 루프·승인·세션·테스트.
- [Card News Studio](card-news-studio/README.md): Claude Agent SDK / OpenCode CLI, 프로젝트별 세션·부분 수정·PNG/PDF·웹앱·Tailscale Serve.

각 폴더의 README에서 설치와 실행 방법을 확인하세요. `uv.lock`을 포함했습니다. API 키, 인증 정보, 개인 작업 기록은 포함하지 않습니다.

`assets`의 화면과 카드 이미지는 수업용 가상 행사 자료를 사용한 실제 예제 엔진 출력입니다. 예제 엔진은 AI를 호출하지 않으며 실제 모델 연결 검증과 구분합니다.
